Features:
   - Aesthetic: Modern Hacker/Minimalist Monospace with a dark theme, green accents, and monospace fonts.
   - Entry Page: index.ejs serves as a "SYS_BOOKSHOP // ENTRY" with links to sub-pages.
   - Shop Page: Displays books (joined with authors and genres) and reviews.
   - Events Page: Displays events and event_registrations.
   - Backend Page: Displays customers, orders, and order_items.
   - Backend: Node.js/Express app (app.js) using the pg client.


  To Run the App:
   1. Ensure you have a PostgreSQL database named books.
   2. Execute the improved schema and seeding scripts:
      - SQL/PostGre/book_data/book_tables_improved.sql
      - SQL/PostGre/book_data/seeding_improved.sql
   3. Navigate to the app directory: cd SQL/PostGre/book_data/webapp
   4. Install dependencies: npm install
   5. Run the server: node app.js
   6. Open your browser at http://localhost:3000.

   * For the Bookstore (Admin):
       * Added forms in the [BACKEND] page to add new books (with dropdowns for authors and genres) and create new events.
       * Updated the backend logic to handle these additions and refresh the database.
   * For Customers:
       * Buy Books: In the [SHOP] page, customers can now specify their CUSTOMER_ID and a quantity to purchase a book. The system automatically creates an order
         record, adds the order items, and updates the inventory stock.
       * Write Reviews: Customers can now leave a rating (1-5) and a comment for any book directly from the shop catalog.
       * Book Event Tickets: In the [EVENTS] page, a registration form allows customers to sign up for upcoming events.


  How to use:
   1. Navigate to [BACKEND] (/admin) to find your CUSTOMER_ID (or add a new book/event).
   2. Go to [SHOP] (/shop) to buy books or leave reviews using your ID.
   3. Go to [EVENTS] (/events) to register for upcoming store events.
